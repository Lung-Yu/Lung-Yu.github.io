# 整合式頁頭樣式 (Integrated Header Styles)

## 功能說明
此CSS文件提供CV元件中整合式頁頭的樣式，包含個人簡介與聯絡資訊的合併顯示。採用現代化的雙欄設計，以創建清晰有序的視覺層次。

## 主要元素
1. **頁頭容器** (`.cv-integrated-header`)
   - 整體頁頭區塊，具有漸層背景與陰影
   - 設有響應式轉換，適應不同螢幕尺寸

2. **雙欄佈局** (`.cv-integrated-layout`) 
   - 採用Flexbox實現左右兩欄
   - 在較小螢幕上縱向堆疊

3. **個人簡介區** (`.cv-intro-section`)
   - 包含姓名、職稱與簡短介紹
   - 重點突出姓名與職稱，使用主色調增強視覺焦點

4. **聯絡資訊區** (`.cv-contact-section`)
   - 結構化展示各種聯絡方式
   - 整合圖示，增加可讀性
   - 互動效果：滑鼠懸停時微小上移與陰影變化

5. **語言切換器**
   - 定位於右上角，方便用戶切換語言

## 色彩使用
- 運用CSS變數管理色彩系統
- 主色調用於標題與重點文字
- 次要色調用於圖示與輔助元素
- 背景採用微妙漸層增加層次感

## 響應式行為
- 在768px斷點下轉換為單欄設計
- 聯絡資訊區重新排列為水平排列
- 語言切換器重新定位確保可用性

## 相關元件
此樣式與CV.tsx主元件密切相關，特別用於實現頁頭的重新設計要求。
